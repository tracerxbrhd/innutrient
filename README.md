# Innutrient

Innutrient rewards balanced, varied, and well-prepared diets without replacing Minecraft's hunger system.

Food fills data-driven nutrient groups such as fruits, vegetables, grains, proteins, and sugars. A bounded memory of recent meals produces a clear 0–100 Food Variety Score, so varied foods and nutrient compositions matter instead of only the last item eaten. Repeating the same food gradually reduces only its nutrition efficiency, while meals made from several useful groups earn Meal Quality bonuses. Sustain a healthy range to improve Diet Quality and gain modest survival benefits; long deficiencies and excessive sugar have practical consequences.

The responsive Nutrition Dashboard brings balance, Diet Quality, Food Variety, recent meals, nutrient target zones, and active survival modifiers into one clear U-API screen. Food tooltips explain individual meals, while complex vanilla and modded food inherits its composition from recipes and NeoForge Common Tags automatically.

- Minecraft 1.21.1 and 26.2 on separate release branches
- NeoForge
- Requires [U-API](https://github.com/tracerxbrhd/u-api)
- Optional support for major food mods; none are required
- Fully configurable through server config and datapacks
- English and Russian localization

Modpack authors can redefine groups, override any food profile, add compatibility datapacks, and configure sustained effect rules. Technical details and the current compatibility matrix live in [`docs/`](docs/).
